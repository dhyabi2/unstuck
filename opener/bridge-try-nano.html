How to use it

1 Find a USDC x402 service
Any API that returns HTTP 402 with a USDC price. Below is a list of known services.
2 Proxy through the bridge
GET /proxy?target=<url-encoded-endpoint>
The bridge converts the USDC price to Nano and returns a Nano x402 response.
3 Pay with Nano
Send the Nano amount to the bridge address. Nano is instant and feeless.
4 Verify
POST /verify-payment {"block_hash": "<64-hex-hash>"}
The bridge confirms the payment on-chain and returns the API response.

What is Nano (XNO)?

  • Instant: settles in under 1 second — no blocks to wait for
  • Feeless: no gas, no fees — every raw goes to the recipient
  • Permissionless: no account needed to receive — just generate an address
  • Divisible: 10^30 raw per XNO — microtransactions work natively
